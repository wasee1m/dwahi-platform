## 4. الإطار والمكونات المشتركة

### 4.1 الترويسة والتذييل (الموقع والبوابة)
- **الترويسة:** الشعار؛ القائمة (المعدات، قطع الغيار، الصيانة، من نحن، الفروع، تواصل)؛ البحث؛ السلة مع العدد؛ الحساب أو "دخول"؛ مبدل اللغة (يحافظ على نفس الصفحة)؛ زر واتساب عائم في الجوال.
- **التذييل:** الروابط، الفروع المختصرة، الشبكات الاجتماعية، روابط التطبيقات، السياسات، الرقم الضريبي والسجل التجاري للشركة.

### 4.2 المكونات
| المكون | الوصف | يُستخدم في |
|--------|-------|-----------|
| شارة الحالة | نص + لون من 01 §9.2 | كل القوائم والتفاصيل |
| الخط الزمني | حالات بأوقاتها والمنفّذ (للإدارة) أو تسمية العميل (للبوابة) | C-14، C-17، A-09 |
| عرض المال | `1,250.500 ر.ع.` بخط أرقام ثابت العرض، ومحاذاة الأرقام في الجداول | كل مكان |
| حقل الجوال | مفتاح الدولة + التحقق من الصيغة العمانية | W-14، W-09، C-03 |
| محدد الموقع | خريطة + بحث + "موقعي الحالي" + المحافظة والولاية + الوصف | C-04 |
| رافع الملفات | سحب وإفلات، معاينة، تقدم، استئناف، حدود الحجم (NFR-11) | C-07، C-15، A-02 |
| ملخص المبالغ | المجموع، الخصم، الضريبة، الرسوم، الإجمالي | C-09، C-11، A-06 |
| المحادثة | فقاعات + مرفقات + "آخر تحديث" + زر تحديث | C-09، C-14، C-17 |
| جدول البيانات | بحث، فلاتر، ترتيب، ترقيم، تحديد متعدد، تصدير، أعمدة قابلة للإخفاء | لوحة الإدارة |

| عد تنازلي | للصلاحية والمهلة | C-09، A-08 |

## 5. الحالات العامة لكل صفحة

كل صفحة فيها بيانات تُصمم بخمس حالات:

| الحالة | المطلوب |
|--------|---------|
| التحميل | هيكل (Skeleton) بشكل المحتوى، دون دوّار في منتصف الصفحة |
| فارغة | رسالة توضح السبب + إجراء تالٍ (مثلاً: "لا توجد معدات في أسطولك بعد" + "أضف معدة") |
| خطأ | رسالة مفهومة + "إعادة المحاولة" + معرّف التتبع في الأخطاء غير المتوقعة |
| ممنوع | لموظف بلا صلاحية: "لا تملك صلاحية لهذه الصفحة" دون كشف البيانات |
| نجاح الإجراء | إشعار منبثق (Toast) قصير + تحديث الصفحة في مكانها |
