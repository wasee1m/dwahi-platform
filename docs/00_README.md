## 1. عن المشروع

منصة رقمية لشركة **ضواحي البادية** (DWAHI-ALBADIA LLC)، ورشة في صناعية العوهي بصحار تعمل منذ 1995 (التفاصيل في 01_srs.md §1.1). تغطي المنصة **بيع المعدات الثقيلة** و**قطع الغيار** و**الصيانة والإصلاح**، وتتكون من:

| المكوّن | المستخدمون | الغرض |
|---------|-----------|-------|
| الموقع الإلكتروني العام | الزوار، العملاء | التعريف بالشركة، كتالوج المعدات والقطع، طلب عروض الأسعار، شراء القطع |
| بوابة العميل (ويب) | العملاء (أفراد وشركات) | متابعة العروض والطلبات والصيانة والفواتير وإدارة الأسطول |
| تطبيق العملاء (Android + iOS) | العملاء | نفس وظائف البوابة مع إشعارات فورية وطلب صيانة بالصور والموقع |
| تطبيق الفنيين (Android + iOS) | فنيو الورشة (20 فنياً) | تنفيذ أوامر العمل داخل الورشة: الصور والقطع والوقت والاختبار، ويتحمّل انقطاع الشبكة |
| لوحة الإدارة (ويب) | موظفو الشركة | المبيعات، الصيانة والتوزيع، القطع، المالية، المحتوى، التقارير |

**خارج النطاق:** تأجير المعدات، سوق متعدد البائعين، المزادات، التمويل والتأجير التمويلي، استبدال نظام ERP.

### قاعدة التحرير
1. أي تعريف (حالة، قاعدة عمل، لون، مهلة زمنية) يُكتب **في مكان واحد فقط** ويُشار إليه بمعرّفه من باقي الملفات. لا نسخ ولا لصق بين الوثائق.
2. عند التعارض: **01_srs.md** هو المرجع، ثم 02 ثم 03.
3. ملف 08 **مولَّد ولا يُعدَّل يدوياً**. بعد أي تعديل على المتطلبات أو القصص أو الشاشات يُشغَّل السكربت `python tools/trace_check.py docs --write` من المجلد الرئيسي للحزمة: يعيد توليد 08 ويفحص الاتساق (معرّفات غير معرّفة، ربط القصص والشاشات في الاتجاهين، الأولويات، ألوان الحالات). أي مشكلة تظهر تُصلح قبل اعتماد التعديل.
4. القرارات تُسجّل في سجل القرارات (القسم 6) بتاريخها.

| البادئة | النوع | مثال | مكان التعريف |
|---------|-------|------|--------------|
| `FR-<وحدة>-NN` | متطلب وظيفي | FR-SRV-01 | 01_srs.md §6 |

| `US-NN` | قصة مستخدم | US-14 | 05_user_stories.md |
| `W-NN` | صفحة ويب عامة | W-03 | 06_web_screens.md |
| `C-NN` | صفحة بوابة العميل | C-17 | 06_web_screens.md |
| `A-NN` | صفحة لوحة الإدارة | A-10 | 06_web_screens.md |

| `Q-NN` | سؤال مفتوح | Q-02 | هذا الملف §5 |

**رموز الوحدات:** AUTH (المصادقة)، ACC (الحسابات والأسطول)، CAT (كتالوج المعدات)، PRT (قطع الغيار)، RFQ (عروض الأسعار)، ORD (طلبات القطع)، PAY (الفواتير والمدفوعات)، SRV (طلبات الصيانة)، WO (أوامر العمل)، TEC (تطبيق الفني)، MSG (المراسلات)، NOT (الإشعارات)، CMS (المحتوى)، ADM (الإدارة)، RPT (التقارير)، INT (التكاملات).

**الأولوية:** Must (ضروري للإطلاق) / Should (مهم، يمكن تأجيله أسابيع) / Could (تحسين).
**المرحلة:** P1 = النسخة الأولى (MVP)، P2 = المرحلة الثانية، P3 = لاحقاً.
